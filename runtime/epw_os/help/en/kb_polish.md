# Polish Characters

The full alphanumeric keyboard (for description fields, not numeric
fields) does not have a separate, eighth row of keys for Polish
diacritical characters — so as not to make the whole keyboard bigger.

Instead, Polish characters (ą, ć, ę, ł, ń, ó, ś, ź) are typed by
**holding down** the corresponding base letter (a, c, e, l, n, o, s, z)
for a moment, instead of a short tap. The letter "z" has two accented
variants (ź and ż) — repeated holds of that letter cycle between them.

A short tap always types the plain base letter — holding it down is the
only way to reach the Polish-character version.
