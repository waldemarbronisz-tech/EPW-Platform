# Language

**Settings → Language...** lets you pick the interface language from
the available list. The choice is saved to the project file.

**The change applies immediately, with no restart** — after clicking
OK on a different language, the window briefly rebuilds itself in
place and reopens on Main View in the new language. This works the
same way in Kiosk Mode, without exiting the kiosk or needing the
Engineer PIN.

This help page is also available in more than one language — help
content opens in whichever language is active at the moment it's
opened; if a given topic has no translation yet for the selected
language, its English version is shown instead.
