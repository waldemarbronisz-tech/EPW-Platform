# Reading State, What the Colors Mean

## State Column

Digital Inputs shows **ON**/**OFF**. Control Outputs shows
**OPEN**/**CLOSED** (the switching-device convention).

## LED Indicator

The round indicator next to the state:

- **green** — the signal is active (ON / CLOSED)
- **gray** — the signal is inactive (OFF / OPEN)

## Timestamp

Updates automatically on every state change for that channel — it shows
the moment of the last change, not the current time.

## Simulation Mode

In simulation mode, digital input values can be manually forced by an
Engineer for testing purposes — see
[Forcing an Output State (Force)](help://dio_force).
