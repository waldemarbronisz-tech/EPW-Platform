# Exporting to CSV

Both the event log (Events) and historical data (Historian — see
[Exporting Historical Data](help://hist_export)) can be exported to CSV
files, but these are two separate export mechanisms exporting different
data.

## Exporting from the event log

1. Set a filter on the Events page (optional) — the export only
   includes rows currently visible after the search and group filters.
2. Click **Export CSV**, or use the right-click context menu on a row
   to export a single event.
3. Choose the destination file.

The CSV column headers are the same English names as the on-screen
table headers (Timestamp, Priority, Group, Object, Event, User, Mode,
Result) — regardless of the interface language, so the file can be
opened and processed consistently elsewhere.
