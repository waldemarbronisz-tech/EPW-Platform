# Everything Else

The rest of the Settings menu is described in its own chapters, to
avoid repeating the same content twice:

- **Change PIN...** — see [Changing a PIN](help://al_change_pin)
- **On-Screen Keyboard** — see [Turning It On](help://kb_enable)
- **Theme...** — see [Visual Themes](help://set_theme)
- **Feature Configuration...** — see [Feature Configuration](help://set_feature_config)
- **MQTT...** — see [MQTT Integration](help://mqtt_what)
- **Training Mode** — see [Training Mode](help://saf_training_mode)
- **Kiosk Mode...** — see [Entering and Exiting](help://kiosk_enter_exit)

**Project → Project Properties...** and **Project → Recently Opened**
live in the separate Project menu, not in Settings — see
[The Project Menu](help://gs_project_menu). File → New/Open/Save/Save
As/Export/Import are covered in [The File Menu](help://gs_file_menu).
