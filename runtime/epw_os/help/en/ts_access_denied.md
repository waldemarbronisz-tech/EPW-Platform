# "Access Denied" — What to Do

This message appears when you try to perform an action that requires a
higher access level than the one you're currently logged in at — it
spells out exactly which level is required.

**The program never prompts for a PIN at that moment.** To continue:

1. Close this message.
2. Click the access level switch on the top bar.
3. Choose the required level and enter the PIN.
4. Go back to the action you were trying to do and try again.

The full list of what requires which level is in
[What Each Level Can Do](help://al_matrix). Every such denial is also
recorded to the audit log.
