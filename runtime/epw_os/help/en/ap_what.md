# What an Analog Point Is

An analog point is a single measurement channel — e.g. a temperature
sensor, a humidity sensor, or a 4-20mA signal. Unlike digital
inputs/outputs (a fixed 64 channels, dictated by physical terminals),
the number of analog points is **arbitrary** — you add and remove them
freely, to match your actual installation.

The Analog Inputs table shows, for each point: tag, description,
current value (with unit), unit, timestamp of the last change, technical
note, and a Configure button.

See also: [Adding and Removing Points](help://ap_add_remove),
[Configuration](help://ap_config).
