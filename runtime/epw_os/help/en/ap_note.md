# The Technical Note and What It's For

The technical note is a short, free-text field on each analog point —
a place for information that doesn't fit any other field, e.g. a
sensor model, which bus it's connected to, or an input module number
("DHT11, 1-Wire bus, ELA-02 module").

It's edited by double-clicking directly in the Analog Inputs table, the
same way as Description and Unit — it requires the Engineer level. It
has no effect on value conversion or on how the point works — it's a
purely descriptive field for whoever services the installation later.
