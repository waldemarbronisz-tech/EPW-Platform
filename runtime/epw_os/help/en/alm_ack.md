# Acknowledging and What It's For

Acknowledging (the **Acknowledge** button in the Action column) means
an operator has noticed the alarm — it requires the **Operator** level.

The button only appears for alarms that actually need it: active and
unacknowledged, or cleared but not yet acknowledged. After clicking,
the row records who acknowledged it and when (shown in the
Acknowledged column).

## What it's for

Acknowledging distinguishes "nobody has seen this yet" from "someone
has noticed it". An alarm that cleared on its own but was never
acknowledged still shows up as needing attention — the program doesn't
let an event simply disappear without a trace. The same applies to the
system-health fault latch described in
[System Health Monitoring](help://saf_kernel) — it's acknowledged
through this exact same Alarms page.
