# Adding and Removing Points

Requires the Engineer level.

## Adding a point

1. Click **Add Point** above the Analog Inputs table.
2. Enter a unique tag name (e.g. `AI.Garden.SoilMoisture`) — the only
   required field in this window. The name must be unique across the
   whole system (it can't clash with any other tag, e.g. a DI/DO tag).
3. Choose the signal type and, if needed, the ranges (see
   [Configuration](help://ap_config)).
4. Confirm.

The new point appears in the table with an empty description, unit, and
note — fill them in directly in the table by double-clicking the
relevant cell.

**Note**: a point's tag cannot be changed later in this window — it's a
fixed identifier set once, at creation. To rename it, you have to
remove the point and add it again under the new name.

## Removing a point

1. Select the row in the table.
2. Click **Remove Point**.
3. Confirm — this cannot be undone.
