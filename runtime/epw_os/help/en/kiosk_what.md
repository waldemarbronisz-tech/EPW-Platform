# What It Is and What It's For

Kiosk Mode is a way of running the program designed for the target
device (an Orange Pi with a touchscreen, in a control cabinet) — the
program takes over the whole screen, with no window frame and no way
to accidentally minimize it or switch to the desktop.

In Kiosk Mode, the menu bar is hidden for the User and Operator levels
— only the diagram and working pages are visible. Once the level is
raised to **Engineer**, the menu bar reappears, so service work (e.g.
changing settings) can be done without leaving the kiosk — and once the
level drops again (manually or through automatic logout), the bar
disappears again.

See also: [Entering and Exiting](help://kiosk_enter_exit),
[Kiosk Mode vs. Fullscreen Mode](help://kiosk_vs_fullscreen).
