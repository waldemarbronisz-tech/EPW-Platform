# Turning It On

The (floating) on-screen keyboard is turned on and off in **Settings →
On-Screen Keyboard** — available at every level, no PIN.

When it's on, touching/clicking any text or numeric field in the
program's tables (e.g. a digital input's description, an analog
point's description) automatically opens the right kind of keyboard next
to that field. Turning the switch off closes any keyboard that happens
to be open.

On a device with no physical keyboard (an Orange Pi with a touchscreen),
starting with the `--kiosk` parameter turns this on by default, unless
the operator has already deliberately turned it off in Settings — that
choice is remembered between runs.

See also:
[Floating and Built-In Keyboards](help://kb_floating_embedded).
