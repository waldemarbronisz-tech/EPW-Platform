# Setting Descriptions

The Description column in both tables (Digital Inputs and Control
Outputs) is editable by double-clicking — the exact same mechanism in
both places.

## How to do it

1. Log in as Engineer (editing a description requires this level).
2. Double-click the Description cell for the channel you want.
3. Type the new text.
4. Confirm with Enter, or click elsewhere.

The change is saved immediately to the project file and appears in the
event log as a "Description changed from ... to ..." entry. The default
description is something like "Digital Input Channel 5" — until someone
changes it.

Below Engineer, the cell is read-only — double-clicking does not open
an editor. Even an attempt to change it by bypassing the interface would
still be rejected at the moment it's actually saved, not just visually.
