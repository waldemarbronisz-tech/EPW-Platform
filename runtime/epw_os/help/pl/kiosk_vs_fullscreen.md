# Różnica między trybem kiosku a trybem pełnoekranowym

To dwa zupełnie osobne mechanizmy, mimo że oba pokazują program na
całym ekranie.

| | Tryb pełnoekranowy (Widok → Tryb pełnoekranowy, F11) | Tryb kiosku |
|---|---|---|
| Dostępność | każdy poziom, bez PIN-u | wejście i wyjście wyłącznie Engineer |
| Ramka okna | bez zmian | usunięta |
| Pasek menu | zawsze widoczny | ukryty poniżej Engineer |
| Wyjście | F11, Esc albo dwuklik w obszarze roboczym | wyłącznie PIN Engineera |
| Cel | wygoda, więcej miejsca na ekranie | zabezpieczenie stanowiska operatorskiego przed przypadkową/niepowołaną zmianą |

Tryb pełnoekranowy jest wyłączony i niedostępny, gdy aktywny jest tryb
kiosku — kiosk przejmuje pełną kontrolę nad stanem okna, żeby nie było
drugiej, niewymagającej PIN-u drogi do zmiany tego stanu.
