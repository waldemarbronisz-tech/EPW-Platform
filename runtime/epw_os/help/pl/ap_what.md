# Czym jest punkt analogowy

Punkt analogowy to pojedynczy kanał pomiarowy — np. czujnik temperatury,
wilgotności czy sygnał 4-20 mA. W odróżnieniu od wejść i wyjść
cyfrowych (stała liczba 64 kanałów, wynikająca z fizycznych zacisków),
liczba punktów analogowych jest **dowolna** — dodajesz i usuwasz je
swobodnie, tak jak wygląda Twoja instalacja.

Tabela Analog Inputs pokazuje dla każdego punktu: tag, opis, aktualną
wartość (z jednostką), jednostkę, znacznik czasu ostatniej zmiany,
notatkę techniczną oraz przycisk Configure.

Zobacz też: [Dodawanie i usuwanie punktów](help://ap_add_remove),
[Konfiguracja](help://ap_config).
