# Wygaszanie ekranu

**Ustawienia → Wygaszanie ekranu...** — po ustawionym czasie
bezczynności (ruch myszy, kliknięcie, klawisz) ekran przygasa,
przykryty jednolitą nakładką. Dowolny dotyk, kliknięcie lub klawisz
natychmiast go budzi.

Ustawienie 0 minut wyłącza wygaszanie całkowicie. Wartość jest
zapamiętywana na tym konkretnym urządzeniu (nie w pliku projektu).

To mechanizm **niezależny** od 5-minutowego automatycznego wylogowania
opisanego w [Automatyczne wylogowanie](help://al_timeout) — wygaszenie
ekranu nigdy nie zmienia poziomu dostępu, a obniżenie poziomu dostępu
nigdy nie wygasza ekranu. To dwie zupełnie osobne rzeczy, które akurat
reagują na tę samą bezczynność.
