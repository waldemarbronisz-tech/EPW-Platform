# Pozostałe

Reszta pozycji w menu Ustawienia jest opisana w swoich własnych
rozdziałach, żeby nie powtarzać tej samej treści dwa razy:

- **Zmień PIN...** — patrz [Zmiana PIN-u](help://al_change_pin)
- **Klawiatura ekranowa** — patrz [Włączanie](help://kb_enable)
- **Motyw...** — patrz [Motywy wizualne](help://set_theme)
- **Konfiguracja funkcji...** — patrz [Konfiguracja funkcji](help://set_feature_config)
- **MQTT...** — patrz [Integracja MQTT](help://mqtt_what)
- **Tryb ćwiczebny** — patrz [Tryb ćwiczebny](help://saf_training_mode)
- **Tryb kiosku...** — patrz [Wejście i wyjście](help://kiosk_enter_exit)

Menu **Projekt → Właściwości projektu...** i **Projekt → Ostatnio
otwierane** znajdują się w osobnym menu Projekt, nie w Ustawieniach —
patrz [Menu Projekt](help://gs_project_menu). Plik →
Nowy/Otwórz/Zapisz/Zapisz jako/Eksport/Import są opisane w
[Menu Plik](help://gs_file_menu).
