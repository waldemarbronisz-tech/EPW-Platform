# Nadawanie opisów

Kolumna Opis w obu tabelach (Digital Inputs i Control Outputs) jest
edytowalna dwuklikiem — dokładnie tak samo w obu miejscach.

## Jak to zrobić

1. Zaloguj się jako Engineer (edycja opisu wymaga tego poziomu).
2. Kliknij dwukrotnie komórkę w kolumnie Opis dla wybranego kanału.
3. Wpisz nowy tekst.
4. Zatwierdź klawiszem Enter albo kliknij gdzie indziej.

Zmiana zapisuje się natychmiast do pliku projektu i trafia do rejestru
zdarzeń jako wpis "Description changed from ... to ...". Domyślny opis
to np. "Digital Input Channel 5" — dopóki nikt go nie zmieni.

Poniżej Engineera komórka jest tylko do odczytu — dwuklik nie otwiera
edytora. Próba zmiany z pominięciem interfejsu (np. programowa) i tak
zostanie odrzucona przy faktycznym zapisie, nie tylko na poziomie
wizualnym.
