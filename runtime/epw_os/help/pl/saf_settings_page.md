# Strona nastaw

Strona **Protection Settings** pokazuje drzewo funkcji zabezpieczeniowych
pogrupowanych w kategorie, a w nich — poszczególne stopnie. Dla każdego
stopnia widoczne są: pole włącz/wyłącz, źródło pomiaru, nastawa,
histereza, zwłoka czasowa, akcja, aktualny status, aktualna wartość
pomiarowa oraz statystyki (liczba zadziałań, wyłączeń, czas działania).

Kolory statusu: zielony (READY — gotowy), żółty (PICKUP — pobudzony),
czerwony (TRIP — zadziałał), niebieski (BLOCKED — zablokowany), szary
(DISABLED — wyłączony).

Edycja jakiejkolwiek nastawy, włączanie/wyłączanie stopnia oraz reset
statystyk wymagają poziomu **Engineer** — bez żadnego wyjątku (także w
trybie symulacji). Zmiana nastawy pokazuje dodatkowe okno potwierdzenia
przed zapisaniem.

Osobna strona **Engineer Mode** pozwala Engineerowi przeprowadzić
formalny test weryfikacyjny wybranego stopnia zabezpieczenia i zapisuje
jego wynik w postaci raportu — patrz
[Engineer Mode (weryfikacja zabezpieczeń)](help://saf_engineer_mode).
