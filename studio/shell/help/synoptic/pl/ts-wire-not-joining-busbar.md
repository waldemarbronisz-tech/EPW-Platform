# Przewod nie laczy sie z szyna

OBJAW: nowy przewod przebiega obok szyny zbiorczej, ale nie liczy sie z nia do jednej sieci.

PRZYCZYNA: dotkniecie musi wypasc DOKLADNIE na odcinku szyny (dowolny punkt jej dlugosci, ale musi lezec na niej geometrycznie), a nie tylko blisko niej - patrz [5.4](help://synoptic/sch-wire-style).

CO ZROBIC: powieksz widok wokol szyny, upewnij sie ze przyciaganie do siatki jest wlaczone, i zakoncz (albo zacznij) przewod dokladnie na punkcie lezacym na linii szyny.
