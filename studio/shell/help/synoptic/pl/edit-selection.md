# 9.1 Zaznaczanie: klikniecie, ramka, Shift, Ctrl+A

Klikniecie zaznacza pojedynczy element (obiekt, przewod, miernik, panel albo ramke); Shift+klik dodaje albo usuwa element z biezacego zaznaczenia. Przeciagniecie po pustym miejscu plotna rysuje ramke zaznaczenia - obejmuje kazdy element CALKOWICIE w niej zawarty.

Ctrl+A (albo Cmd+A) zaznacza wszystko na biezacym ekranie naraz - obiekty, przewody i mierniki razem. Zaznaczenie jest zawsze jednego "rodzaju" na raz w typowym uzyciu: Properties pokazuje "Multiple objects selected" zamiast szczegolow, jesli zaznaczenie miesza wiecej niz jeden rodzaj elementow.
