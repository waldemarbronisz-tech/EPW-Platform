# 2.1 New Project

`File > New` creates an empty SCHEMATIC project (asks for a name). It starts from nothing: no locations, cards, devices or objects - those must be added by hand, in the order described in [2.2](help://synoptic/start-order).

If the open project has unsaved changes, `New`/`Open...` ask for confirmation before discarding them (the browser's own standard dialog - its wording cannot be customized).
