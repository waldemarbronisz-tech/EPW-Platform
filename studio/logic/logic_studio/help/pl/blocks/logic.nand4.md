Czterowejściowa odmiana [NAND](help:block:logic.nand): FALSE tylko przy
**wszystkich czterech** wejściach TRUE.

### Przykład: nadzór kompletu warunków

Cztery czujniki drzwi w szafie: gdy wszystkie zgłaszają „otwarte”
jednocześnie, to najpewniej uszkodzona wiązka, nie cztery otwarte drzwi —
NAND-4 → FALSE → sygnał „sprawdź okablowanie”.
